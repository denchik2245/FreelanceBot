# Расширение правил отбора, 14 октября 2026

Этот отчёт фиксирует первый вариант расширения и прогон 43 примеров до последующего
уточнения пользователя про любые дополнительные работы. После уточнения смешанный
заказ «дизайн сайта + упаковка» также допускается, а текущий набор расширен до 51 примера.

Рабочий промпт `config/prompts/project_filter.txt` обновлён по требованиям пользователя:

- дизайн или разработка подходящего сайта вместе с обязательным логотипом допускаются;
- разработка обычных лендингов, сайтов-визиток и корпоративных/многостраничных сайтов
  допускается на WordPress, других CMS и кодом;
- любые реальные работы на Tilda допускаются, включая правки, блоки, код, интеграции
  и магазины; упоминание платформы в отрицании или только как примера не считается
  реальной задачей на Tilda;
- описания длиннее 6000 символов передаются AI целиком и не получают автоматический
  `unclear` из-за длины.

Для разработки вне Tilda сложными считаются магазины с корзиной/оплатой,
маркетплейсы, личные кабинеты, CRM/ERP, приложения, собственная серверная логика
и сложные системы бронирования. Обычные формы, готовые виджеты, блог и информационный
каталог без корзины/оплаты не делают сайт сложным. Дизайн сложного продукта без
обязанности его разработки допускается. Отдельные логотипы и другие задачи вне
веб-направления, вакансии в штат и неоплачиваемые конкурсы по-прежнему не подходят.

Профиль исполнителя дополнен разрешёнными услугами. При этом не добавлялись
утверждения о неподтверждённом опыте или разработке конкретных кейсов портфолио.
Предварительный фильтр ключевых слов дополнен формами «Тильде»/«Тильды», WordPress
и Webflow, чтобы такие задачи доходили до AI.

## Живой API

Проверены 43 заказа через прямой DeepSeek API, модель `deepseek-flash`,
размышления отключены. Набор: `eval/projects-expanded.json`.
Решения во всех 43 случаях совпали с ожидаемыми:

- ложные допуски: 0;
- пропущенные подходящие: 0;
- ошибки API: 0.

В набор входят 24 прежних примера с пересмотренной разметкой и 19 дополнительных.
Прежняя разметка сохранена отдельно в `eval/projects.json`; сравнивать этот результат
со старыми метриками GigaChat без учёта смены правил нельзя.

Проверены, в частности, «сайт + логотип», лендинг на WordPress, обычный корпоративный
сайт, простой каталог, готовый виджет записи, адаптивная вёрстка, магазин на Tilda,
правка кнопки и нестандартная JS-интеграция Tilda с ERP. Сложный магазин WordPress,
сервис с кабинетами, CRM и мобильное приложение отклонены.
Два описания превышают 6000 символов: обычный лендинг принят; заказ с обязательной
собственной серверной логикой, ролями и кабинетами в конце описания отклонён.

Подробный локальный отчёт: `data/eval-deepseek-expanded-2026-10-14.json`.
Это проверка подготовленных примеров, а не независимая оценка точности на новых
реальных заказах. Рабочий бот не перезапускался, провайдер в `.env` не менялся;
тесты не отправляли сообщения VK и не меняли рабочую базу.

## Код

173 автоматических теста пройдено, линтер изменённого кода прошёл.
Тесты подтверждают, что длинное описание целиком доходит до основной модели,
проверяющей модели и генератора откликов. Проверка кандидатов второй моделью
для длинных описаний также больше не отключается.

Ограничение модели на размер контекста продолжает действовать: при его превышении
API вернёт ошибку, решение не будет отправлено как проверенное. Длина сама по себе
больше не определяет пригодность заказа.

## Повторный запуск

```bash
AI_ENABLED=true AI_PROVIDER=deepseek \
AI_FILTER_PROMPT_PATH=config/prompts/project_filter.txt \
PYTHONPATH=src .venv/bin/python -m freelance_bot.evaluate_ai \
  --live --dataset eval/projects-expanded.json --limit 43 \
  --output data/eval-deepseek-expanded.json
```

Команда расходует платные токены API и сохраняет отдельный отчёт.

## Уточнение: любые дополнительные работы

Пользователь уточнил, что логотип был примером: дополнительные работы любого вида
вместе с подходящим дизайном или созданием сайта также нужно принимать. Промпт и профиль
обновлены: обязательные тексты, полиграфия, упаковка, презентации, email-письма,
оформление соцсетей, SEO, аналитика и другие сопутствующие задачи не блокируют веб-проект.
Самостоятельные заказы на эти работы без подходящего веб-проекта остаются неподходящими.
Ограничение на полноценную разработку сложных продуктов вне Tilda сохранено.

После этой правки отдельно проверены 9 смешанных/пограничных заказов через DeepSeek:
пример 33 и новые примеры 44–51. Все 9 решений совпали с ожидаемыми, ошибок API нет.
Сайт с упаковкой, печатными материалами, текстами или соцсетями принимается;
только упаковка/соцсети или только листовки/email без сайта отклоняются;
полноценная разработка сложной CRM вне Tilda по-прежнему отклоняется.

Локальный подробный отчёт: `data/eval-deepseek-additional-work-2026-10-14.json`.
Остальные примеры в этом дополнительном прогоне повторно не вызывались; результат
9/9 не следует представлять как новый полный прогон всех 51 примера.
